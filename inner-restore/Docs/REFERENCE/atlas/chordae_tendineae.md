# 腱索（形の仕様書）

印の意味：【全文】本文を読んだ／【要旨】要旨のみ／【抜粋】検索結果の抜粋のみ（本文未読）／【計算】資料の数値からの計算／【未確認】出所を確かめられなかった。
（心臓の資料全体は `../heart.md`。出所の略号・写真の番号もそちらと共通）

## 名前（日本語・英語）
腱索（けんさく）／chordae tendineae（heart strings）

## 種類（細胞・組織・器官・物質）
組織（線維性の結合組織のひも。乳頭筋と房室弁をつなぐ）

## 実際の大きさ（数値と、髪の毛の太さ約70〜80µm などとの比較）
- 僧帽弁の腱索：8〜12本、1本の長さ **15〜20 mm**、直径 **約0.45 mm**。【抜粋】[Khalighi2016 が MillingtonSanders1998 を引用]（原著で未確認）
- 太さは1本ずつ違う。細いものは弁の自由縁に、太いもの（支柱腱索）は縁から離れた所に付く。【全文】[Wiki-MV]
- 表面のコラーゲンの波の縞：幅 **11 µm**。【要旨】[MillingtonSanders1998]
- 比較：太さ 0.45 mm は髪の毛 約6本分。主人公から見ると直径 約380 m の綱、長さ 約13〜17 km。縞の幅 11 µm は赤血球 約1.4個分、主人公から見て 約9 m。【計算】

## 形と比率（3Dモデルを作れる精度で数値と言葉で）
- **枝分かれする網**のようなひも。1枚の弁尖に何本も付く。【全文】[Wiki-Chord]【要旨】[MillingtonSanders1998]
- 写真⑩：乳頭筋の円錐形の先から、細く白い糸が**扇のように**何本も広がり、途中で**枝分かれ**して細くなりながら弁の縁へ向かう。写真の観察
- 断面（芯から外へ）：**密なコラーゲンの芯** → **密な弾性線維の層** → **なめらかな扁平な内皮**（心内膜）。【要旨】[MillingtonSanders1998]
- 芯のコラーゲン線維は、**平面の波**のように**そろって**波打ち、ひもの周り全体を巡る。【要旨】[MillingtonSanders1998]
- 模型の目安：長さ：太さ ≒ 30〜45：1 の、根もとで太く先で細かく分かれる白いひも。表面に、長軸に直角の細かい縞（波）。【計算】

## 表面のつくり
- なめらかな扁平な内皮で覆われる。【要旨】[MillingtonSanders1998]
- ゆるんだ状態で、光を当てると**縞もよう**（幅 11 µm）に反射する。引っぱると縞（波）がのびて消える。【要旨】[MillingtonSanders1998]

## 内部に見えるもの
- 血管がない。コラーゲンと弾性線維。【要旨】[MillingtonSanders1998]
- 細胞（線維芽細胞など）の密度：【未確認】

## 色と透け具合（生体での見え方）
- 写真⑦（病気で厚くなった腱索、死後）：**白い**太いひも。写真⑩（白黒）でも周りより明るく光を反射する。写真の観察
- 正常な腱索の生きた色・透け具合：【未確認】（保存できたカラー写真は病気のもののみ）

## 動き方（速度などの数値があれば）
- 心房が縮み弁が開くとき：**ゆるむ**。心室が縮み弁が閉じるとき：**ぴんと張り**、弁尖が心房側へめくれる（逸脱）のを防ぐ。【全文】[Wiki-Chord]
- 乳頭筋は心室が縮む少し前から縮み、張力を保つ。【全文】[Wiki-Pap]
- 張ると波打つコラーゲンがまっすぐになり、急な力をやわらげる。ゆるむと弾性線維が波に戻す。【要旨】[MillingtonSanders1998]
- 弁の開閉そのものは圧の差で起こり、腱索は関わらない。【全文】[Wiki-HV]

## 周囲との並び方（密度・間隔・向き）
- 乳頭筋は5本（右心室3、左心室2）。左心室の2本（前外側・後内側）から僧帽弁へ。【全文】[Wiki-Pap]
- 肉柱が多い心室の内面から、乳頭筋が柱のように立ち上がる（写真⑥⑩）。写真の観察

## 体の中での働き
- 弁が逆向きに開かないよう支え、血液の逆流を防ぐ。【全文】[Wiki-Chord][Wiki-Pap]

## ほかの細胞との関係
- **病気のとき**：
  - 年をとると波が長くなり乱れ、心内膜の下に結合組織のふくらみ、芯は細くなる → 伸びて切れることがある。【要旨】[MillingtonSanders1998]
  - 腱索が切れると強い僧帽弁の逆流。【全文】[Wiki-Chord]
  - 僧帽弁逸脱症では腱索が伸び、後ろの弁尖の腱索がよく切れる。【全文】[Wiki-MV]
  - リウマチ性心疾患では腱索が厚くなる（写真⑦の説明文）。【全文】[Commons 説明文：CDC]

## 初登場時の説明文の案（1〜2文、専門用語には言い換えを添える。大人向けの落ち着いた口調）
「腱索。心室の筋肉の柱と弁をつなぐ、白い丈夫なひもです。心臓が縮むたびにぴんと張って、弁が裏返らないように支えています。」
