# 単球（形の仕様書）

印の意味：【全文】本文を読んだ／【要旨】要旨のみ／【抜粋】検索結果の抜粋のみ（本文未読）／【計算】資料の数値からの計算／【未確認】出所を確かめられなかった。
（血管の資料全体は `../vessel.md`。出所の略号もそちらと共通）

## 名前（日本語・英語）
単球／monocyte

## 種類（細胞・組織・器官・物質）
細胞（白血球の一種。血管の外へ出てマクロファージになる）

## 実際の大きさ（数値と、髪の毛の太さ約70〜80µm などとの比較）
- 直径 **15〜22 µm**。血液の中でいちばん大きい細胞。【全文】[Wiki-Monocyte]
  白血球の表では 15〜30 µm。【全文】[Wiki-WBC]
  いずれも塗り広げた標本の値と思われる。浮いた（流れている）状態の大きさ：【未確認】（好中球は標本 12〜15 µm、浮いた状態 8.85 µm【全文】[Wiki-Neutrophil] なので、単球も標本の値より小さい可能性が高い）
- 比較：赤血球の 約2〜3倍、髪の毛の太さの 約4分の1、主人公の 約8〜11倍。【計算】
- 白血球の 2〜10%（表では 5.3%）。【全文】[Wiki-Monocyte][Wiki-WBC]

## 形と比率（3Dモデルを作れる精度で数値と言葉で）
- 流れの中ではほぼ丸い。【未確認】（一般の白血球の記述。単球について出所を確かめていない）
- 核：楕円で、くびれて**豆形・腎臓形**に見えることが多い。大きく、なめらか。細胞質が広い。【全文】[Wiki-Monocyte][Wiki-WBC]
- 模型の目安：直径 約15〜18 µm の球。中に、細胞の半分強を占める腎臓形の核。【計算】（比率は推定）

## 表面のつくり
- 内皮のセレクチンに結びつく糖鎖（PSGL-1 など）をもち、内皮の上を転がる。【全文】[Wiki-Extrav]
- 表面のひだ・突起の形：【未確認】

## 内部に見えるもの
- 異物を処理する小胞（小さな袋）が多い。【全文】[Wiki-Monocyte]
- 顆粒は目立たない（表では「なし」）。【全文】[Wiki-WBC]

## 色と透け具合（生体での見え方）
- 生体での色の記述はない。【未確認】　ヘモグロビンをもたないので、赤血球のような赤色はない。【計算】
- 標本の青紫は染色の色。使わない。

## 動き方（速度などの数値があれば）
- 血液を 1〜3日巡ったあと、組織へ入る。【全文】[Wiki-Monocyte]
- 血管の外へ出る順序：呼ばれる → 内皮の上を転がって減速 → しっかり付く → 内皮を通り抜ける。【全文】[Wiki-Extrav]
- 転がる速さ（マウス細静脈、主に好中球）：約40 µm/s（P-セレクチン）、3〜7 µm/s（E-セレクチン）。【抜粋】（単球・動脈の値は【未確認】）
- 一部の単球は、炎症のない内皮の上を長い距離**這って見回る**。【要旨】[Auffray2007]（マウス）　ヒトでも見回りが示されている。【全文】[Wiki-Monocyte]　這う速さ：【未確認】

## 周囲との並び方（密度・間隔・向き）
- 血液中にまばらに流れる（白血球は血液の体積の 約1%、その 5% ほど）。【全文】[Wiki-WBC]

## 体の中での働き
- 組織へ入ってマクロファージや樹状細胞になり、異物を食べ、免疫の合図を出す。【全文】[Wiki-Monocyte]

## ほかの細胞との関係
- 内皮の VCAM-1 に呼ばれ、内皮の下へ入りこむ。M-CSF でマクロファージに変わる。【全文】[Wiki-Athero]
- **病気のとき**：動脈の内膜で LDL を食べ続け、泡沫細胞になる（`foam_cell.md`）。【全文】[Wiki-Athero]

## 初登場時の説明文の案（1〜2文、専門用語には言い換えを添える。大人向けの落ち着いた口調）
「単球。血液の中でいちばん大きな、豆の形の核をもつ白血球です。血管の壁を見回り、必要な所で壁の中へもぐりこんで、食べる細胞（マクロファージ）に変わります。」

## 確認の方法と未確認の点
- **確認の方法**：大きさ・核の形は百科事典（本文）、見回りはマウスの生体観察（要旨）。
- **未確認の点**：浮いた状態の大きさ、表面のひだ、転がる・這う速さ（ヒト・動脈）、生体の色。
- **食い違い**：直径 15〜22 µm と 15〜30 µm。
