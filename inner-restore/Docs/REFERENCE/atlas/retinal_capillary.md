# 網膜毛細血管（形の仕様書）

印の意味：【全文】本文を読んだ／【要旨】要旨のみ／【抜粋】検索結果の抜粋のみ（本文未読）／【画像】画像を見た／【計算】資料の数値からの計算／【未確認】出所を確かめられなかった。

## 名前（日本語・英語）
網膜毛細血管／retinal capillary（網の名前：表層血管網 SVP、中間毛細血管網 ICP、深層毛細血管網 DCP、放射状乳頭周囲毛細血管網 RPCP）

## 種類（細胞・組織・器官・物質）
組織（内皮細胞・基底膜・周皮細胞でできた、いちばん細い血管）

## 実際の大きさ（数値と、髪の毛の太さ約70〜100µm などとの比較）
- **内径**（ヒト。提供眼の乳頭周囲、レクチンで内腔側を染めた計測、対照群 4,320か所）：【全文】[An2020]

  | 網 | 内径 平均 ± 標準誤差 [範囲] (µm) |
  |---|---|
  | 全体 | 6.6 ± 0.9 [4.3〜8.3] |
  | RPCP | 6.2 ± 1.1 [4.3〜8.3] |
  | SVP（論文では SCP） | 6.7 ± 0.8 [5.2〜7.9] |
  | ICP | 6.8 ± 0.8 [4.5〜8.1] |
  | DCP | 6.6 ± 0.8 [4.3〜7.7] |

- 生体（補償光学、健康な3人の123本）：内径 3.2〜8.4 µm。【抜粋】[Bedggood2023]
- 中心窩の近く（ヒトの提供眼、中心窩から鼻側へ 2 mm）では、4つの網のあいだで径に差はない。【要旨】[Chan2012]
- 一般の毛細血管は 5〜10 µm。【全文】[Wiki-Capillary]
- 髪の毛（約 70〜100 µm）の 約 10〜15分の1。赤血球（直径 7.8 µm）と同じか、それより細い。
- 壁の厚み：内皮細胞の薄い部分＋基底膜（約 0.3 µm。ヒト網膜で 292 ± 24 nm【全文】[Roy2020]）＋周皮細胞の突起。壁全体の厚みの数値：【未確認】

## 形と比率（3Dモデルを作れる精度で数値と言葉で）
- 円い断面の細い管が、枝分かれしてはつながり、網目（ループ）を作る。行き止まりはない。
- **網目の間隔**（毛細血管と毛細血管の間の距離。ヒト、乳頭周囲、対照群）：【全文】[An2020]

  | 網 | 間隔 平均 ± 標準誤差 [範囲] (µm) |
  |---|---|
  | 全体 | 99.5 ± 13.7 [59.1〜130.3] |
  | RPCP | 89.4 ± 12.6 [59.1〜110.4] |
  | SVP | 96.8 ± 15.9 [70.6〜130.3] |
  | ICP | 105.5 ± 9.8 [87.6〜127.0] |
  | DCP | 106.6 ± 8.4 [92.4〜127.1] |

  → 管の太さ：網目の間隔 ≒ 1：15。髪の毛の太さ（70〜100 µm）とほぼ同じ間隔で、髪の10分の1ほどの細い管が張りめぐらされている。【計算】
- 中心窩の近くでは、網目の面積は内側の2つの網で最も小さく、密度は内網状層を養う網で最も高い。【要旨】[Chan2012]
- 網ごとの形：【全文】[Campbell2017]【要旨】[Chan2012]
  - RPCP：神経線維の束に沿って、長くまっすぐ、互いに平行に走る。横のつながりが少ない。
  - SVP：太い動脈・静脈と毛細血管が混じる。黄斑では、中心窩へ向かって枝分かれしながら集まり、中心窩の縁の輪で終わる。
  - ICP、DCP：小葉状の網。DCP と神経線維層の網は平面的（1枚の層）、その間の網は立体的。
  - 網と網の間には毛細血管のない層があり、縦に走る短い枝が貫いてつなぐ。静脈側の縦の枝のほうが見分けやすい。
- 動脈のすぐ脇には、毛細血管のない帯（動脈周囲の無毛細血管帯）がある。【全文】[McLeod2012]
  サルの黄斑の血管鋳型の写真でも、動脈に沿って網目のない暗い帯が見える。【画像】（Webvision Simple Anatomy Fig. 19）
- 同じ写真で見た網目の形【画像】：管は直線ではなく、ゆるく波打ちながら不規則な多角形の網目を作る。網目の大きさは不ぞろい。
  太い動静脈から毛細血管へは、急に細くなるのではなく、数回の枝分かれで細くなる。
- 中心窩には毛細血管がない（無血管域、直径 450〜600 µm）。その縁を1重の輪が囲む。【全文】[WV-Simple][Campbell2017]

## 表面のつくり
- 外面：周皮細胞のこぶと突起が、管の周りの 85% 以上を覆う。【要旨】[Frank1990]　その外をミュラー細胞の突起の鞘が 90% 以上包む（マウスとサル）。
  表層の網では、アストロサイトも一緒に包む。【全文】[Grimes2025]
- 内面：なめらか。窓（穴）のない連続型。核の所だけ内側へ盛り上がる。（`endothelial_cell.md`）

## 内部に見えるもの
- 1列に並んで流れる赤血球（1 mm あたり 約 60個）と、その間の血漿。ときどき白血球と血小板。【全文】[Gu2021][Martin2009]

## 色と透け具合（生体での見え方）
- 壁は無色透明。色は中の血液の赤。毛細血管1本は細すぎて、ふつうの眼底写真には写らない（見えるのは太い動静脈）。【画像】（健常眼底写真）
- 網膜の毛細血管網は、蛍光造影や OCT 血管撮影、補償光学で初めて見える。ふつうの蛍光造影では表層の網しか見えず、中間と深層の網は写らない。【全文】[Campbell2017]
- 主人公の大きさで見た場合（事実からの整理）：透明な細い管の中を、赤い円盤が1列に、間をあけて流れていく。
  赤血球のいない区間は、ほぼ無色（血漿は麦わら色）。

## 動き方（速度などの数値があれば）
- 赤血球の速さ：平均 1.70 mm/s（0.93〜3.32 mm/s。5人、15本）。光の点滅刺激の最中 1.72、後 1.80 mm/s で、ほぼ変わらない。【全文】[Warner2021]
  → 100 µm の網目1辺を、約 0.06 秒で通り抜ける。【計算】
- 流れは心拍に合わせて脈打つ。中心窩の周りの毛細血管を流れる白血球の速さは、8人の平均 1.30 ± 0.40 mm/s（個々の白血球で 0.34〜3.28 mm/s）で、
  1拍の中で速い時と遅い時の差が 3〜4割ある。【全文】[Gu2021][Martin2009]
- 白血球は、いちばん細い毛細血管を通るとき、変形しなければ通れないことが多い。【全文】[Martin2009]
- 光の刺激で毛細血管は広がる。変化は中間の網で最も大きい。【全文】[Grimes2025]

## 周囲との並び方（密度・間隔・向き）
- **層と深さ**（硝子体側から）：【全文】[Campbell2017]【要旨】[Chan2012]

  | 網 | ある深さ |
  |---|---|
  | RPCP | 神経線維層（乳頭の周りだけ） |
  | SVP | 主に神経節細胞層（＋内網状層の浅い部分） |
  | ICP | 内網状層の深い部分〜内顆粒層の浅い部分（内顆粒層の内側の縁に密度の山） |
  | DCP | 内顆粒層の深い部分〜外網状層（内顆粒層の外側の縁に密度の山） |

- 別の言い方では、表層＝神経線維層、中間＝内網状層、深層＝外網状層。【全文】[Huang2020]（マウスとヒト）
- **外網状層より外（外顆粒層、視細胞の内節・外節）には毛細血管がない。** まれに外顆粒層まで入ることがある。【全文】[WV-Simple]
  外側は、脈絡毛細血管板（内腔 20〜50 µm、窓あり）から養われる。【全文】[Lutty2010]
- 周辺部の網膜では、ICP と DCP が1つの網になる。乳頭の周りでは RPCP と SVP が重なる。【全文】[Campbell2017]
- 酸素の濃度は、中間の網の近くで最も低い（そこでの消費が、供給に対して大きい）。【全文】[Grimes2025]

## 体の中での働き
- 網膜の内側の層（神経節細胞、双極細胞など）に酸素と栄養を届け、老廃物を運び去る。【全文】[WV-Simple]
- 血液網膜関門として、血液の成分の出入りを厳しく選ぶ。【全文】[Huang2020]
- 網膜の動脈は、互いの連絡がほとんどない「終動脈」。詰まると、その先の区域を別の道から養うことができない。【全文】[Wiki-Choroid]

## ほかの細胞との関係
- 内皮細胞・周皮細胞・基底膜が壁を作り、ミュラー細胞（とアストロサイト）が外から包む。この組を「神経血管単位」と呼ぶ。【全文】[Grimes2025]
- **病気のとき**：
  - 糖尿病（非増殖期、ヒト提供眼）：内径が 6.6 → 9.1 µm に広がる。網目の間隔が 99.5 → 133.3 µm（最大 564 µm）に広がる。
    とくに DCP（106.6 → 178.1 µm）と RPCP（89.4 → 113.7 µm）で目立つ。【全文】[An2020]
  - 周皮細胞と内皮細胞が失われ、基底膜だけの空の管（血が流れない）が残る。その周りに毛細血管瘤ができる。基底膜は 約 2倍に厚くなる。【全文】[Hammes2011][Roy2020]
  - 動脈の閉塞：血流が滞ると、血の柱が途切れ途切れになる（boxcarring）。内側の網膜は白く濁る。【全文】[EyeWiki-RAO]

## 初登場時の説明文の案（1〜2文、専門用語には言い換えを添える。大人向けの落ち着いた口調）
「網膜の毛細血管。太さは髪の毛の約10分の1で、赤血球が1列になってやっと通れる細さです。
網膜の内側に3層の網を張り、光を受け取る神経細胞に酸素を届けています。」

## 確認の方法と未確認の点
- **確認の方法**：寸法と層は文章の記述（本文と表）から書いた。網目の形は、サルの黄斑の血管鋳型の走査電顕写真（Webvision Fig. 19）を
  画像として見て確かめた。ただしサルであり、白黒の鋳型なので、色と壁の質感は分からない。
  ヒトの生体での毛細血管の画像（OCT 血管撮影、補償光学）は見ていない。
- **未確認の点**：
  - 中心窩の近くでの網目の間隔の実数（Chan 2012 は要旨のみで、数値が載っていない）。
  - 壁全体の厚み。分岐の角度、1区間（分岐から分岐まで）の長さ。
  - 縦につなぐ枝の太さと密度。
  - ヒトでの刺激による径の変化の量。
- **食い違い**：内径は標本 6.6 ± 0.9 µm、生体 3.2〜8.4 µm、別論文の引用値 8 µm【抜粋】。代表値 5〜7 µm。
  網の数え方は、2層（表層・深層）、3層（表層・中間・深層）、4層（＋RPCP）と資料で違う。場所によって実際に変わるため（黄斑の周りで3〜4、周辺で2）。
