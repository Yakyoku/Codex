# 歩き・走りの腕の振り（実際の人の動きの確認）

2026-11-27、持ち主の指摘（腕が体にくっついて見える・不自然）を受けて、実際の人の歩行・走行の計測の報告で確認した。

## 歩き
- 腕は、肩を中心にした振り子のように前後へ振れる。肩の振れ幅は 約20〜25°（ふつうの速さ）。速く歩くほど大きくなる。
- ひじの曲げ伸ばしの幅は 約15〜30°。後ろへ振れたときはほぼ伸び、前へ振れたときに軽く曲がる。
- 足と逆の腕が前へ出る（左足が前のとき、右腕が前）。
- 手は腰の横を通る（体には触れない）。前へ出た手は、少しだけ体の中心へ寄る。

## 走り
- ひじを 約90°に曲げたまま、肩から振る（平らな道で 約90°。60〜70°をすすめる指導もある）。
- 手は、下では腰の少し後ろ、上ではあばら（胸の横）の高さまで。ひじを後ろへ引く動きが大きい。
- 肩は力を抜き、上がらない。胴のひねりは小さく。

## 直す前の動き（数値で確認）
- 上腕がほぼ真下のまま胴に付き、ひじは歩きで 51〜58°・走りで 76〜84°に曲がったまま、前腕だけが外へ開いていた。
- 手首は一度も体の後ろへ行かず、いつも体の前にあった（わきを締めて前腕を外へ出す、作った歩き方に見える原因）。
