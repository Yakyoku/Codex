# Web の予算表（最初の目標値。実機の結果で見直し、変更は理由とともに下の「変更の記録」に書く）

## 容量（圧縮後）
| 項目 | 目標 | 現在（2026-11-22・第1部） |
|---|---|---|
| 最初のダウンロード（タイトル〜ステージ1開始） | 25MB 以内 | 約 0.3MB（プログラム 256KB＋メッシュ 47KB） |
| ステージごとの追加 | 30MB 以内 | — |
| 全体（画面版） | 250MB 以内 | 約 0.3MB |
| VR 版（別集計） | 画面版と共通素材＋VR 専用 20MB 以内 | 共通のみ |
| タイトル画面まで（光回線の PC） | 10秒以内 | 未計測（実機待ち） |

容量の内訳はビルドのたびに `Docs/build-sizes/history.jsonl` に追記される（プログラム・テクスチャ・メッシュ・音・フォント）。

## 速さ
| 品質段階 | 対象 | fps の目標 | 描画解像度の上限 |
|---|---|---|---|
| PC 高画質（WebGPU） | RTX 4060 級・4K テレビ | 常時 60 | 内部 1440p 相当から開始（実機診断で決める） |
| モバイル高画質（WebGPU） | 最新の iPad・iPhone | 60 | DPR 2 まで（実機診断で決める） |
| 互換（WebGL 2） | WebGPU 不可の環境 | 30 以上 | DPR 1.5 まで |
| VR（WebGL 2＋WebXR） | Quest 3 単体 | 常時 72（可能なら 90） | 既定の解像度×1.0、フォビエーション 1、MSAA 4 |
