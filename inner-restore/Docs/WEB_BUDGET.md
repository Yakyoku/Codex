# Web の予算表（最初の目標値。実機の結果で見直し、変更は理由とともに下の「変更の記録」に書く）

## 容量（圧縮後）
| 項目 | 目標 | 現在（2026-11-27・全7ステージ） |
|---|---|---|
| 最初のダウンロード（タイトル〜ステージ1開始） | 25MB 以内 | 約 3MB（プログラム 0.4MB＋目の模型・潜行士・画像・フォント。声は読む行だけを順に取りに行く） |
| ステージごとの追加 | 30MB 以内 | 模型 0.2〜1.8MB＋その器官の声 約1MB（選んだ声1種ぶん） |
| 全体（画面版） | 250MB 以内 | 41.3MB（声 32.5MB＝220行×4種、模型 6.5MB、画像 1.6MB、プログラム 0.4MB、フォント 0.35MB。進捗ページは別） |
| VR 版（別集計） | 画面版と共通素材＋VR 専用 20MB 以内 | 共通素材のみ（VR 専用は軽い模型 .lo.glb で、上の模型 6.5MB に含む） |
| タイトル画面まで（光回線の PC） | 10秒以内 | 未計測（実機待ち） |

容量の内訳はビルドのたびに `Docs/build-sizes/history.jsonl` に追記される（プログラム・テクスチャ・メッシュ・音・フォント）。

## 変更の記録
- 2026-11-22：初版。
- 2026-11-22（M1）：M1 の場面の実数。描画回数 約12（床・深部・血管・周皮細胞・赤血球の群れ1・光の円盤と筋・線維・微粒子・潜行士13部品・ビーム）、
  三角形 約14万（床 3.3万、血管 1.3万、周皮細胞 1.3万、赤血球 LOD0 1万×22個、潜行士 2.4万）。VR は赤血球 LOD1・線維と微粒子を減らして約 8万。
  半透明の重なりは最大3層（床・血管の壁・周皮細胞）。影を落とす光は 0。いずれも上限内。fps は実機の結果待ち。
  潜行士の GLB は未圧縮で 0.64MB と大きい（関節の親子関係を保つため）。M2 で圧縮に対応させる。
- 2026-11-27（全7ステージ・最終の実測）：全21区域を `node scripts/measure-zones.mjs` で測り直した（結果は `Docs/build-sizes/zone-tris.jsonl`）。
  画面版（互換）の三角形は 最大 77.5万（鼻の線毛・粘液）、次いで 76.8万（脳の皮質）— 上限 80万の内。VR は 最大 39.9万（心臓の傷あと）、次いで 37.4万（鼻）— 上限 40万の内。
  描画回数は 画面版 21〜35、VR 16〜31（上限 200／100）。全区域で超過なし。ただし上限すれすれの区域（鼻・皮質・傷あと）は、実機で fps が足りなければ最初に減らす候補。
  容量は 全体 41.3MB（上限 250MB）。fps・WebGPU の見え方・Quest 3 での負荷は、この環境では測れない（実機の結果待ち）。
