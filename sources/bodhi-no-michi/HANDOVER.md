## 金剛力士は Blender で作る（持ち主の指示）
- `tools/blender/build_nio.py` を Blender 4.2 LTS で実行すると、阿形・吽形の造形（`public/models/nio-bl-a.bin`／`nio-bl-un.bin`）ができる。
  手順：Blender をダウンロード（download.blender.org、約 350MB）→ Human Base Meshes（CC0、約 100MB）→
  `blender -b human_base_meshes_bundle.blend --python tools/blender/build_nio.py -- a <出力.bin> [プレビュー.png] 6`（`a` を `un` にすると吽形）
- 中身：土台の人体 → 腕を T 字へ（Blender の骨と自動の重み）→ 筋肉を盛る → 忿怒の顔 → 裳・帯・腕輪・髻・輪 → 頂点色 → ゲームの骨（20 本）へ自動の重み → ゲームの形式で書き出し。関節の位置もファイルに入り、ゲームはそれで骨組みを作る。
- 既知の不具合：上腕の腕輪の縁が、腕を上げると脇の下に少し見える。阿形の顎の脇にわずかな折れ目。

## 法戦の作り替え（持ち主の「対峙が面白くない・直感的でない」への対応）
- 抽象的な「阿の拍で攻め、吽の拍で受け」をやめ、**受けて、返す**の駆け引きにした。
  - 構え → 蓮のまわりに墨の輪が出て縮む → 重なって朱になった瞬間に「受」＝見事（時間が一瞬止まり、墨しぶき・揺れ・澄んだ音）
  - 見事の後、尊格の構えが開く（隙）→「攻」で返し（印可が大きく進む）。ふだんの攻めは尊格が受け止める（わずか）
  - 吽形の間外し（輪が途中で止まる）、二連打、地を踏む波（「躱」で跳ぶ）、連打への戒めの一手
  - 最初の受けと返しは、時間を止めて教える（修行の難しさでは止めない）
- 判定の文字（見事／返し／受け／崩れ／見切り）、連の数、画面上部の合図（受ける！／返す！／躱す！／待て）
- 実装：`src/game/prologue.ts`（startAttack・parried・tryHit・telegraph・cue）、`src/ui/howto.ts`（輪・判定・合図・遊び方）
