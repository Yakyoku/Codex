## 4. 素材の決まり
- テクスチャは原則 1K、主役級のみ 2K。形式は WebP（KTX2 は M0 で使えるか確かめる）。
- 土の粒や組織の模様はシェーダーで作る。画像は「焼き込んだ AO・法線・厚み」に絞る。
- メッシュは圧縮し、LOD を3段（近・中・遠）。同じ形はインスタンス化する。
- 日本語の文字は HTML と CSS（画面版）。VR のパネルは実行時にキャンバスへ描いてテクスチャにする。
- 音は Ogg ではなく、iOS で確実に鳴る AAC（.m4a）を基本にする（M0 で再生を確かめる）。

## 2026-11-25 互換モードの三角形を減らした
- 内訳を出せるようにした（`world.stats.by`：粒の種類×LOD ごとの三角形と個数）。互換：LOD2（遠く）約 75 万、LOD1（中）約 62 万。
- 互換・VR だけ、LOD1 を道のすぐそばに絞り（`lite`）、互換の粒の密度を 0.7 → 0.45 にした。**互換 137 万 → 75 万三角形**（予算 50 万にはまだ届かない）。
- 遠く用のさらに粗い形（LOD3）を meshoptimizer で作る案は、粒の UV の継ぎ目が多く、三角形がほとんど減らなかった（220 → 130〜260）ので取りやめた。
  次の案：Blender で、UV を持たない（法線の焼き込みなし）粗い形を別に作る。壁の奥の粒は、まとめて 1 枚の「奥の壁」の面に置き換える。

## 2026-11-26 互換・VR を予算内に
- 遠くの粒（LOD2）を、互換・VR だけ 80 面の形（LOD3）にした。LOD3 は、読み込んだ LOD2 の形に 80 面の球を貼りつけて実行時に作る（`world.ts` の shrinkWrap）。UV は近い頂点から。
- **互換 78 万 → 36 万三角形（予算 50 万）、VR 88 万 → 40 万（予算 40 万）**。前後の比較画像：`public/progress/img/m1/lod3cmp.webp`（見た目はほぼ同じ）。確認用 `?nolod3`。
- モバイル高画質は 248 万（予算 80 万）。iPad の実機で 182 万でも平均 60 fps だったので、予算そのものを実機診断の結果で見直す（M1 の締めくくり）。
