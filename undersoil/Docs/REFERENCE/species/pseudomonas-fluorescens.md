# 形の仕様書：蛍光性シュードモナス（*Pseudomonas fluorescens* 群）

台帳：`Docs/SPECIES.md`「シュードモナス」。ステージ1では、水の膜がつながると泳ぎ出す細菌として登場する。

## 確認の方法

**ほぼ文章のみ。** *P. fluorescens* そのものの写真は、染色した標本2点と、紫外線を当てた集落1点しか入手できなかった。**染色していない生きた細胞の写真と、本種の鞭毛の写真は見ていない。** 形・色・鞭毛は、下の文章資料の数値から作ること。制作後、進捗確認ページで実物の顕微鏡写真と見比べてもらう必要がある。

## 寸法

| 項目 | 値 | 根拠 |
|---|---|---|
| 細胞の長さ | 3.1±0.8µm | BOSO-Micro（SBW25株。Ping et al. 2013 にもとづく） |
| 細胞の太さ | 0.9±0.1µm | 同上 |
| 形 | まっすぐ、またはごくわずかに曲がった棒。両端は丸い。長さは太さの約3.5倍 | 寸法と写真（染色標本） |
| 鞭毛の位置 | 体の片方の端（極）だけ | Ping et al. 2013（要旨）、BacMap（Pf-5株） |
| 鞭毛の本数 | 株による。SBW25株：平均1.5±1.1本（1本が基本）。Pf-5株：複数の極鞭毛 | BOSO-Micro／BacMap（検索結果の要約） |
| 鞭毛の長さ | 8.4±1.3µm（体の約2.7倍） | BOSO-Micro（SBW25株） |
| 鞭毛の形 | **右巻き**のらせん。約2.5巻き。1巻きの長さ1.76µm、らせんの幅（振れ）0.39µm | Ping et al. 2013（右巻き。要旨）、BOSO-Micro |
| 鞭毛の太さ | 約15〜20nm（別種の電子顕微鏡写真からの目測。本種では未確認） | 写真 |
| 芽胞 | 作らない | BacMap（検索結果の要約） |

**モデルの推奨値**：長さ3µm × 太さ0.9µm のカプセル形。鞭毛は片方の端から1〜3本（個体ごとにばらつかせる。標準は2本）、長さ8µm、右巻きのらせん2.5巻き。鞭毛の太さは見やすさのために誇張してよいが、図鑑に「実物より太く描いている」と書く。

枯草菌との見分け（ゲームで並べたとき）：太さはほぼ同じ（0.9µm と 0.8µm）、長さも近い（3µm）。**形だけでは見分けにくいので、鞭毛の付き方（端だけ／側面全体）と、泳ぎの速さと型（速くて前後に切り返す／遅くて止まっては向きを変える）、芽胞の有無で区別する。** 色で塗り分けて区別してはいけない（どちらも無色）。

## 色と透け具合

- 生きた細胞は**無色で、ほぼ透明**。グラム染色のピンクは染色の色であり、使わない。
- 提案：ごく淡い半透明の白。RGB(222, 230, 225)、不透明度20〜35%。枯草菌よりわずかに透明に（△。グラム陰性菌は細胞壁が薄い、という一般的な性質からの類推で、見た目の差を示す資料は未確認。差をつけなくてもよい）。
- 「蛍光」について：鉄が少ないときに出す黄緑色の色素（ピオベルジン）が、紫外線を当てると青白〜黄緑に光る。色素は細胞の外（まわりの水）に出る。**土の中に紫外線はないので、細胞も、まわりの水も光らない。** 色素が濃い培養液は、ふつうの光の下で淡い黄緑に見えるが、土の中の細胞1個のまわりで色が見えるほど濃くなるかは未確認。色はつけない。
- 内部の構造：光学顕微鏡では見えない。

## 動き

| 項目 | 値 | 根拠 |
|---|---|---|
| 前進の速さ | 毎秒77.6µm（最大102µm）＝体の長さの約25倍 | BOSO-Micro（SBW25株） |
| 泳ぎの型 | 前進（ラン）、後退（バックアップ）、急な方向転換（ターン）、前進と後退の切り替えのときの向き直り、体をくるくる回す動き（フリップ）、その場でとどまる（ホバー） | Ping et al. 2013（要旨） |
| 面の近く | 平らな面の近くでは、円を描いて泳ぐ。速さが落ち、方向転換が増える | 同上 |
| 鞭毛の回転 | 毎秒約2.4回という値が集計表にあるが、単位と条件を確認できなかった（未確認） | BOSO-Micro |
| 水の膜との関係 | 膜が薄いと泳げない。近縁の *P. putida* では、面の上での広がる速さが、−0.5kPa（とても湿った状態）の毎時521µm から、−2.0kPa の毎時14µm まで落ち、それより乾くと鞭毛の効果はなくなった | Dechesne et al. 2010 |

ゲームでの動かし方の提案：
- 水の膜が十分に厚い場所（粒の接点、くぼみ、雨の直後）：すばやい直進と、ぴたりと止まって逆向きに戻る動き、土の粒の表面に沿って円を描く動きを混ぜる。
- 膜が薄い場所：その場でふるえるだけで進めない。膜がつながった瞬間に泳ぎ出す。
- 乾いた場所：動かない（休眠の殻は作らない。乾燥に長く耐えるしくみは、この仕様書の範囲では未確認）。

## ゲームで必要な状態

1. **動けない細胞**：薄い水の膜の中で、土の粒の表面にはりついている。鞭毛は体に沿ってたたまれているか、見えない（△）。
2. **泳ぐ細胞**：上の「動き」のとおり。
3. **面にはりついた集まり**（必要なら）：粘り気のある物質に包まれた数個〜数十個の集まり（バイオフィルム）。シュードモナス属がバイオフィルムを作ることは確認済みだが、形の細部は未確認。

芽胞やシストの状態は**ない**。

## 足してはいけないもの

- 目、顔、口、手足。
- 細胞が光る表現、まわりの水が光る表現（スキャン表示は別）。
- 緑や黄緑、ピンクの体色。
- 芽胞。
- 体の側面から生えた鞭毛、両端から生えた鞭毛。
- くねくね曲がる体（体は硬い棒。動くのは鞭毛）。
- 乾いた場所や薄い膜の中をすいすい泳ぐ表現。
